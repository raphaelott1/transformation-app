☁ GitHub Sync — Automatische Cloud-Sicherung
Daten werden automatisch in deinem GitHub-Account gespeichert — kostenlos, sicher, auf allen Geräten verfügbar.

Einmalig: Erstelle ein GitHub Token unter github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) mit dem Scope gist.

Gist-ID:
Gib diese ID auf einem anderen Gerät ein (mit deinem Token) um dich zu verbinden.
So installierst du die App auf dem iPhone
1Öffne die App-URL in Safari auf deinem iPhone (nicht Chrome!).
2Tippe unten auf das Teilen-Symbol (Rechteck mit Pfeil nach oben).
3Wähle „Zum Home-Bildschirm" — die App erscheint mit eigenem Icon.
4Öffne die App, gehe zu Datensicherung und gib deinen Sync-Code ein um deine Daten zu laden.
So speicherst du in Google Drive
1Klicke auf Backup exportieren — die Datei transformation_backup_DATUM.json wird heruntergeladen.
2Öffne drive.google.com und ziehe die Datei in einen Ordner deiner Wahl (z.B. "90 Tage Transformation").
3Fertig — die Datei ist sicher in der Cloud. Du kannst sie jederzeit herunterladen und hier wieder importieren.
💡Empfehlung: 1× pro Woche exportieren. Alte Backups kannst du in Google Drive einfach löschen.
